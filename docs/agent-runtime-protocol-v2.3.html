AuditOps v2.3 runtime protocol

A versioned, stateless filing-verification runtime. It does not issue audit opinions or perform autonomous statutory audits.

Deployable baseline

safety_hybrid is the deployable baseline. Quantitative tasks are executed and released through the deterministic metric executor. Narrative tasks load a frozen, section-bounded evidence scope and ask the model for exact quotes only. capability_agent remains a research ablation because its one legal tool action is schema-forced.

State machine

  1. Validate and sanitize AgentTaskInputV2.3.
  2. Build a complete stateless ContextPackV2.3; fail with CONTEXT_OVERFLOW rather than truncate.
  3. Execute only the task registry’s deterministic operation.
  4. For narrative tasks, request one schema-constrained quote selection.
  5. Reconstruct release text, claims, and citations deterministically.
  6. Verify scope, period, arithmetic, citations, exact support, and extraction policy.
  7. Release, safely refuse, or return a typed failure. At most one safe repair is possible.

The only model-facing absence-of-support refusal is NO_DIRECT_EVIDENCE. Evaluator-only negative causes retain whether a source task represented a retrieval miss, an unsupported claim, or another hard negative. Those causes never enter a model request.

Identity and immutability

The task binds the subtype policy and its hash. The run identity also binds the context, stage schemas, prompt version, semantic model configuration, deterministic executor, operation registry, demonstration pack, and narrative policy. Local model paths remain outside the semantic identity. v2.2 schemas, benchmarks, runs, and reports are not rewritten or dual-read.

Evaluation

Headline narrative measures are answerability, exact extractive support, citation agreement, and preferred-wording exactness. Aggregate proposal accuracy is retained only as a compatibility diagnostic. Results include filing-level macro rates and filing-clustered uncertainty because the cached US benchmark has repeated tasks per filing.
