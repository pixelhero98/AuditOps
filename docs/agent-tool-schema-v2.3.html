Model-authored data

Planning may contain only the exact registered tool call. A narrative terminal answer contains one to three {evidence_id, exact_quote} objects, subject to the task subtype policy. A narrative refusal contains NO_DIRECT_EVIDENCE. The model does not author released prose, claims, citations, uncertainty routing, or evaluator negative causes.

Deterministic data

The runtime constructs answer text, claims, and citations from verified extracts. Tool observations state retrieval_status=SCOPE_LOADED and answerability_assessed=false. Loading the scope never asserts support.
